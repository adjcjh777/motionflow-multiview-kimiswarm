# SOTA Baseline Preparation: VoxelPose & MVPose on H36M True-GT

This directory contains preparation scripts and configs to run the VoxelPose
and MVPose baselines on the corrected, non-circular H36M true-GT protocol
(`S1,5,6,7,8 -> S9/S11`).

> **Do not run these scripts automatically.** They exist to be launched
> manually when the local RTX 4090 is free. Always run
> `check_gpu_free.sh` before starting any GPU-backed baseline.

## Directory Layout

```
scripts/sota_baselines/
├── README.md                          # this file
├── check_gpu_free.sh                  # helper: exit 0 if GPU is idle
├── common_export_h36m_true_gt.py      # export our *_m.npz to baseline format
├── voxelpose_h36m_config.yaml         # VoxelPose run parameters
├── prepare_voxelpose_h36m.sh            # clone / install / export / run
├── mvpose_h36m_config.yaml            # MVPose run parameters
└── prepare_mvpose_h36m.sh             # clone / install / export / run
```

## Quick Start

1. Export the H36M true-GT data once:
   ```bash
   python scripts/sota_baselines/common_export_h36m_true_gt.py
   ```
2. Check GPU availability:
   ```bash
   bash scripts/sota_baselines/check_gpu_free.sh
   ```
3. Run a baseline manually when the GPU is free:
   ```bash
   bash scripts/sota_baselines/prepare_voxelpose_h36m.sh
   # or
   bash scripts/sota_baselines/prepare_mvpose_h36m.sh
   ```

## Outputs

- `tmp/sota_baselines/h36m_true_gt_baseline_format.pkl` — exported H36M true-GT
  (2D/3D poses, confidences, camera parameters, train/val split).
- `tmp/sota_baselines/VoxelPose/` — VoxelPose repo and run outputs.
- `tmp/sota_baselines/MVPose/` — MVPose repo and run outputs.
- `outputs/sota_baselines/` — evaluation logs and metric JSON files.

## Notes

- These baselines are **external** repositories. The prep scripts clone them
  into `tmp/sota_baselines/` the first time they are run.
- The scripts will **not** start a GPU job if the local GPU is busy or if the
  repo is on A800-D (read-only).
- The H36M true-GT labels are in **metres**, matching the `*_m.npz` files
  generated by `experiments/make_h36m_true_gt_metres.py`.
