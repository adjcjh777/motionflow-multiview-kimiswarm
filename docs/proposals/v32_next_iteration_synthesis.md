# v32 Next-Iteration Synthesis (post-v31)

This doc synthesizes five focused v32 proposals generated by the swarm while the v31 top-5 smoke/full runs are running. The goal is to keep the model complex enough for ICRA/CVPR 2027 but avoid the over-engineering that broke v27/v29 TTE.

## Current known failure modes

- v27/v29 TTE (iterative test-time self-evolution) is broken → ~90 mm val.
- v26/v29a overfit after epoch 1–3.
- v28 physical loss had to be tuned down to 0.01 to avoid regression.
- v31 has wired four new modules but no full-run results yet.

## Proposed v32 directions

| # | Direction | Core idea | Expected val_MPJPE effect | Risk |
|---|-----------|-----------|---------------------------|------|
| 1 | **Temporal** — Trajectory Consistency Refiner | Replace TTE with a 1-D temporal CNN + smoothness/drift losses. | Remove 90 mm failure; small 1–3 mm gain | Over-smoothing fast motion |
| 2 | **Geometry** — Ray-conditioned cross-view attention | Add camera-ray Q/K bias to v31 geometry-biased encoder. | 1–3 mm, better outlier handling | Overfit if MLP too large |
| 3 | **Robustness** — Outlier-aware uncertainty triangulation | Use `OutlierViewDetector` + covariance head in the main DLT path. | Lower tail / variance | Chicken-and-egg on bad DLT seed |
| 4 | **Physical** — Root-centered per-joint bounded residuals | Improve v28 physical alignment with per-joint bounds and confidence gate. | 1–3 mm, stabler physical loss | Bounds collapse to no-op |
| 5 | **Training** — Domain-aware view curriculum | Clamp view count to each domain's real camera rig. | 3–8 mm on MPI; flat/H36M | MPI noise amplification |

## Recommended order

1. **Training (domain-aware view curriculum)** — no new model code, only a data/curriculum change; easiest to smoke and the biggest expected MPI gain.
2. **Temporal (TCR)** — removes the broken TTE path and stabilizes inference.
3. **Geometry (ray attention)** — builds on the v31 hierarchical encoder that already shows promise.
4. **Robustness (outlier triangulation)** — depends on (3) and the covariance head; test after geometry improvements.
5. **Physical (bounded residuals)** — only if v31 physical runs show the same instability as v28.

## Validation protocol for each

- Fast local 4090 smoke: 2 epochs, `train_samples=50`, `val_stride=1`.
- Compare against the current v31 baseline (running now) and v29a (28.12 mm first-epoch, but overfits).
- Promote to A800 full only if smoke val_MPJPE is within 5 mm of v31 baseline and no overfit by epoch 2.

## Next action

Wait for v31 local smoke and A800 top-5 full runs to produce first val_MPJPE, then pick the first v32 direction to implement.
