## 5. GPU/CPU scheduling rules

1. **GPU exclusivity:** only one `python` training/eval process on the RTX 4090 at a time. Always run `nvidia-smi` and `ps -ef | grep -E "train_omniview|eval_variable_views"` before launching.  
2. **Start GPU jobs with `nohup` and record the PID:**

   ```bash
   nohup bash scripts/<script>.sh > outputs/<script>_nohup.log 2>&1 &
   echo $!
   ```

3. **CPU tasks can run concurrently**, but avoid I/O-heavy tasks (MPI frame extraction + AIST++ preprocessing) at the same time as a GPU training run that also reads `.npz` files.  
4. **If ablations are still running**, do not launch v80 medium v2; wait until `nvidia-smi` shows no active training/eval process.
