# True-GT Shelf / Campus Detected Leaderboard

> **Date:** 2026-08-11
> **Scope:** Non-circular evaluation on `data/webbridge/shelf_campus_detected/`.  
> 2D input = COCO detections; 3D target = true annotation (`annotation_3d.json`).  
> Generated by `experiments/build_shelf_campus_canonical_from_detection.py`.

## Protocol

- **Data:** `data/webbridge/shelf_campus_detected/` built from
  `detection.json` (real 2D detections) + `annotation_3d.json` (real 3D).
  Labels are **not** a function of the input 2D.
- **Split manifests:**
  - `configs/splits/shelf_campus_detected_true_gt.yaml` (canonical true-GT baseline/eval split)
  - `configs/splits/shelf_campus_detected_smoke.yaml` (smoke-run alias, same paths)
  - train: Shelf seq1 train (346 frames, 5 views) + Campus seq1 train (652 frames, 3 views)
  - val: Shelf seq1 val (87 frames, 5 views) + Campus seq1 val (164 frames, 3 views)
  - 17 joints, units in metres.
- **Non-circularity check** (`scripts/diagnose_circular_labels.py`): direct MJE ≫ 0 mm
  for all `.npz` files, confirming labels are independent of input 2D.

## Key takeaways

1. **Correct protocol changes everything**: the old circular `data/webbridge/shelf_campus/*.npz`
   would have shown DLT ≈ 0 mm and v25 ≈ 17 mm; on the detected true-GT protocol the
   picture is reversed (DLT ≈ 130 mm, v25 ≈ 430 mm).
2. **DLT is a strong baseline** on clean multi-view detections; Iskakov-style learnable
   weighting gives a modest but real gain over plain DLT.
3. **MotionFlow variants need substantial re-tuning / more data** to beat or match
   Iskakov on non-circular data; 25-epoch long runs still fall well short of the
   root-aligned DLT baseline.

## How to reproduce

```bash
# DLT baseline (confidence-weighted + unweighted)
python scripts/run_shelf_campus_true_gt_baseline.py --unweighted

# Iskakov baseline
python experiments/train_iskakov_baseline_shelf_campus.py \
    --protocol shelf_campus --datasets shelf+campus \
    --epochs 30 --batch_size 8 --lr 1e-3 --hidden_dim 32 \
    --log_path outputs/iskakov_shelf_campus_detected.log \
    --ckpt_path outputs/iskakov_shelf_campus_detected.pth

# v25 smoke
bash scripts/run_v25_shelf_campus_noncircular_smoke_local_4090.sh

# v80 smoke
bash scripts/run_v80_mpi_only_noncircular_smoke_local_4090.sh
# then swap manifest to configs/splits/shelf_campus_detected_smoke.yaml

# v80 long run (A800-D, read-only; local script for reference)
bash scripts/run_v80_shelf_campus_detected_long_a800.sh

# v57 long run (A800-D, read-only; local script for reference)
bash scripts/run_v57_shelf_campus_detected_long_a800.sh
```
