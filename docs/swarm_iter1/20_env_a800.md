# A800-D SSH 环境速查

## TL;DR
远程 A800-D 查 GPU、建 conda 环境、rsync 同步数据的最小命令。

## 关键结论

### 1. 查 GPU

    ssh user@a800-d
    nvidia-smi
    nvitop -1
    python -c "import torch; print(torch.cuda.get_device_name(0))"

A800-D 通常 8 卡，注意 CUDA_VISIBLE_DEVICES 占用。

### 2. 建环境

    conda create -n mf python=3.10 -y
    conda activate mf
    conda install pytorch pytorch-cuda=12.1 -c pytorch -c nvidia -y
    conda env export --no-builds > environment.yml

### 3. 同步数据

    rsync -avP --partial ./data/ user@a800-d:/path/to/project/data/
    rsync -avP --exclude="*.pyc" --exclude="__pycache__" ./ user@a800-d:/path/to/project/
