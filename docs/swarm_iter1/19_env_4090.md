# RTX 4090 本地 PyTorch/CUDA 环境调研

## TL;DR
- 主机：Ubuntu 24.04 (WSL2)，内核 6.18.33.2-microsoft-standard-WSL2
- GPU：NVIDIA GeForce RTX 4090（24 GB GDDR6X），驱动 595.79，nvidia-smi 显示 CUDA 兼容版本 13.2
- Python：3.12.3，pip 24.0
- PyTorch 尚未安装；推荐安装 CUDA 12.4 的 PyTorch wheel

## 关键结论
1. GPU 可被识别：nvidia-smi 能列出 RTX 4090，显存 24564 MiB，功耗上限 450W。
2. CUDA 运行时未安装：无 nvcc、无 /usr/local/cuda；驱动层 CUDA 13.2 已就绪，安装 CUDA 12.4 toolkit 与 PyTorch 无兼容性问题。
3. PyTorch 待安装：当前 Python 环境无 torch、numpy 等深度学习依赖。
4. 建议安装命令（针对 RTX 4090 + CUDA 12.x）：

~~~bash
pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124
~~~

5. 安装后验证：

~~~python
import torch
print(torch.__version__)
print(torch.cuda.is_available())
print(torch.cuda.get_device_name(0))
~~~
