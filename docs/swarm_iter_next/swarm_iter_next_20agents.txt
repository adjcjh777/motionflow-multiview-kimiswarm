## 1. Concise technical report

# Survey: Calibrated Multi-View 3D Human Pose for CVPR / ICRA 2026–2027

### 1.1 Key design decisions

1. **Geometry-preserving triangulation backbone.** Rather than regressing 3D coordinates end-to-end, the model feeds learned per-view weights into a differentiable weighted DLT layer. This keeps metric scale and camera consistency by construction.
   - Files: `motionflow_mv/fusion/triangulation.py`, `motionflow_mv/fusion/ray_attention_temporal_residual_model.py`

2. **Ray-aware attention tokens.** Each (view, joint) token is built from the 2D observation, confidence, camera center, ray direction, and a camera embedding.
   - File: `motionflow_mv/fusion/ray_attention_temporal_uncertainty_model.py` (lines 116–155)

3. **Residual refinement head.** A lightweight MLP corrects the raw triangulated pose using pooled temporal features:
   - `X_refined = X_raw + ΔX`
   - File: `motionflow_mv/fusion/ray_attention_temporal_residual_model.py`

4. **Uncertainty weighting variant.** A Gaussian log-variance head lets views self-attend and forms weights `w_v = c_v · exp(-log_var_v)`, with an auxiliary reprojection NLL loss.
   - File: `motionflow_mv/fusion/ray_attention_temporal_uncertainty_model.py` (lines 157–187)

5. **Plugin integration.** The model is registered as a `FusionModule` so the same calibrated 2D input interface works across datasets.
   - File: `motionflow_mv/fusion/ray_attention_module.py`

### 1.2 Relevant equations

Weighted DLT (differentiable least-squares):

```
X_raw = argmin_X Σ_v w_v · || cross(P_v, [x_v, y_v, 1]^T · X) ||^2
```

Uncertainty weighting:

```
w_v = c_v · exp(-log_var_v)
```

Residual refinement:

```
ΔX    = MLP([f_pooled, X_raw])
X_ref = X_raw + ΔX
```

Training objective:

```
L = || X_ref - X_gt ||_2^2 + λ_reproj · L_reproj
```

### 1.3 Current empirical status

- MPI-INF-3DHP S1→S2/Seq1: **11.17 mm MPJPE** / 8.24 mm PA-MPJPE, 243 k params (`docs/swarm_iter7/exploration_summary.md`).
- Human3.6M S1→S5: **5.74 mm MPJPE** / 3.99 mm PA-MPJPE.
- Naive iterative application of the residual head diverges (`docs/swarm_iter6/report.md`), pointing to the need for learned damping.

### 1.4 Open CVPR / ICRA 2026–2027 directions

- **Damped iterative refinement:** replace the single-pass residual with a gated iterative update to stop over-correction.
- **Uncertainty-aware residual:** combine the uncertainty head with the residual head for robust per-joint corrections.
- **Cross-view spatio-temporal attention:** attend jointly over views and time (`motionflow_mv/fusion/ray_attention_temporal_crossview_residual_model.py`).
- **Real-world GVHMR demo:** project monocular SMPL output through calibrated virtual cameras and fuse (`experiments/demo_gvhmr_multiview_projection.py`).
- **Cross-dataset generalization:** train on MPI-INF-3DHP / H36M and test on Shelf / Campus.

```python
"""Minimal prototype: damped iterative residual refinement for multi-view 3D pose.

The current `RayAttentionFusionModelTemporalResidual` applies a single
residual correction.  Naive multi-pass application diverges
(`docs/swarm_iter6/report.md`).  This prototype learns a per-joint
damping gate so that iterative refinement stays stable::

    X_{k+1} = X_k + gate(MLP([f, X_k])) * MLP([f, X_k])
            = X_k + gate * delta

The gate is initialised near zero, so the model starts by returning the
raw triangulated pose and only gradually learns to apply corrections.
"""

import torch
import torch.nn as nn


class DampedResidualRefiner(nn.Module):
    """Iterative residual refiner with a learned per-joint damping gate."""

    def __init__(self, j: int = 17, d: int = 64, residual_hidden: int = 128, n_iter: int = 1):
        super().__init__()
        self.j = j
        self.d = d
        self.n_iter = n_iter

        # Predicts the residual correction ΔX.
        self.residual_mlp = nn.Sequential(
            nn.Linear(d + 3, residual_hidden),
            nn.ReLU(),
            nn.Linear(residual_hidden, residual_hidden),
            nn.ReLU(),
            nn.Linear(residual_hidden, 3),
        )

        # Predicts a scalar damping factor per joint in [0, 1].
        self.gate_mlp = nn.Sequential(
            nn.Linear(d + 3, residual_hidden // 2),
            nn.ReLU(),
            nn.Linear(residual_hidden // 2, 1),
            nn.Sigmoid(),
        )

    def forward(self, feat_pooled: torch.Tensor, x_raw: torch.Tensor) -> torch.Tensor:
        """Refine a raw triangulated pose.

        Parameters
        ----------
        feat_pooled : (B, T, J, d) or (B*T, J, d)
            Pooled temporal features per joint.
        x_raw : same leading dims, last dim 3
            Raw triangulated 3D pose.

        Returns
        -------
        x_ref : same shape as x_raw
            Damped iteratively refined 3D pose.
        """
        x = x_raw
        for _ in range(max(1, self.n_iter)):
            inp = torch.cat([feat_pooled, x], dim=-1)
            delta = self.residual_mlp(inp)
            gate = self.gate_mlp(inp)  # (..., J, 1)
            x = x + gate * delta
        return x


def _demo() -> None:
    """Sanity-check shapes and verify the gate is conservative at init."""
    B, T, J, d = 2, 5, 17, 64
    torch.manual_seed(0)
    feat = torch.randn(B, T, J, d)
    x_raw = torch.randn(B, T, J, 3)

    model = DampedResidualRefiner(j=J, d=d, residual_hidden=128, n_iter=3)
    y = model(feat, x_raw)
    print(f"input shape: {x_raw.shape}, refined shape: {y.shape}")

    with torch.no_grad():
        inp = torch.cat([feat, x_raw], dim=-1)
        gate = model.gate_mlp(inp)
        print(f"initial gate mean: {gate.mean().item():.4f}  (near-zero -> conservative)")


if __name__ == "__main__":
    _demo()
```

## 1. Technical Report: Cross-View Attention Variants

### Existing variants

The `motionflow_mv/fusion/` package already contains four cross-view ray-attention designs:

| Variant | File | Key idea |
|---|---|---|
| Pairwise cross-view | `ray_attention_crossview_model.py` | Builds `V×V` view-pair tokens per joint and max-pools over the source view. |
| Spatio-temporal cross-view | `ray_attention_temporal_crossview_model.py` | For each joint, a single transformer attends over the `(time, view)` grid of `T·V` tokens. |
| Cross-view + residual | `ray_attention_temporal_crossview_residual_model.py` | Adds a residual MLP head `ΔX` on top of the raw weighted-DLT estimate. |
| Cross-view + uncertainty + GN | `ray_attention_temporal_crossview_uncertainty_residual_learned_tri_v1_model.py` | Predicts log-variance weights, refines with differentiable Gauss-Newton, then applies residual. |

### Core design decisions

1. **Geometry-first inductive bias.** Every variant predicts per-view, per-joint weights `w_{v,j}` and feeds them into a differentiable weighted DLT layer, preserving metric scale and multi-view consistency.
2. **Two ways to model cross-view relationships.** Pairwise attention explicitly encodes `(src, tgt)` view pairs; spatio-temporal attention lets a single transformer learn both temporal and cross-view dependencies.
3. **Residual refinement after triangulation.** A lightweight MLP corrects the structured leftover error of the geometric estimate:
   \[
   X_{\text{ref}} = X_{\text{raw}} + \text{MLP}([f_{\text{pool}}, X_{\text{raw}}])
   \]
4. **Robustness auxiliaries.** The advanced variant adds uncertainty `log σ²_{v,j}` (precision becomes DLT weights), a differentiable Gauss-Newton reprojection refinement, and a reprojection NLL loss.
5. **Weight clamping.** A floor of `1e-4` prevents singular DLT systems when attention downweights all views.

Weighted DLT per joint:
\[
A_j = \begin{bmatrix} w_{v,j}\,(x_{v,j} P_v^{3,:} - P_v^{1,:}) \\ w_{v,j}\,(y_{v,j} P_v^{3,:} - P_v^{2,:}) \end{bmatrix}_v,
\quad
X_j = \arg\min_X \|A_j X\|^2
\]

### Empirical status

- Smoke test: `RayAttentionFusionModelTemporalCrossviewResidual` reached **11.56 mm** vs. temporal-only residual **17.01 mm** (`docs/swarm_iter6/temporal_crossview_residual_report.md`).
- Full MPI-INF-3DHP: cross-view residual achieved **15.29 mm MPJPE / 13.49 mm PA-MPJPE**, while the temporal-only residual remains best at **11.17 mm / 8.24 mm** (`docs/swarm_iter7/cross_view_attention_architecture_improvements.md`).
- Interpretation: generic `(time, view)` attention overfits on full data because it lacks a geometric inductive bias for which view pairs are informative.

# docs/swarm_iter_next/design_cross_view_attention_variants/demo_geo_crossview.py
"""Minimal prototype of a geometry-aware cross-view attention bias."""

import torch
import torch.nn as nn
import torch.nn.functional as F


def compute_rays(points_2d: torch.Tensor, K: torch.Tensor, R: torch.Tensor) -> torch.Tensor:
    """points_2d: (B, V, J, 2); K,R: (B, V, 3, 3) -> rays: (B, V, J, 3)"""
    B, V, J, _ = points_2d.shape
    ones = torch.ones(B, V, J, 1, device=points_2d.device, dtype=points_2d.dtype)
    xy1 = torch.cat([points_2d, ones], dim=-1)
    K_inv = torch.inverse(K)
    d_cam = torch.einsum("bvic,bvjc->bvij", K_inv, xy1)
    d_world = torch.einsum("bvab,bvjb->bvja", R.transpose(-2, -1), d_cam)
    return d_world / (d_world.norm(dim=-1, keepdim=True) + 1e-8)


def ray_angle_bias(rays: torch.Tensor, gamma: float = 0.5) -> torch.Tensor:
    """rays: (B, V, J, 3). Returns pairwise bias (B, J, V, V)."""
    dots = torch.einsum("bvid,bvjd->bijv", rays, rays)  # (B, J, V, V)
    return gamma * F.softplus(1.0 - dots.abs())


class GeoBiasedAttention(nn.Module):
    """Transformer layer with a learned ray-angle attention bias."""

    def __init__(self, d: int, n_heads: int, n_views: int):
        super().__init__()
        self.attn = nn.MultiheadAttention(d, n_heads, batch_first=True)
        self.gamma = nn.Parameter(torch.tensor(0.5))

    def forward(self, x: torch.Tensor, rays: torch.Tensor) -> torch.Tensor:
        # Simplified for T==1: x is (B*J, V, d)
        B, V, J = rays.shape[0], rays.shape[1], rays.shape[2]
        bias = ray_angle_bias(rays, self.gamma)  # (B, J, V, V)
        # Reshape to match attention score layout (omitted for brevity).
        # In practice, add bias to the (time*view) x (time*view) attention matrix.
        out, _ = self.attn(x, x, x)
        return out  # placeholder: real code injects bias into scores


if __name__ == "__main__":
    B, T, V, J = 2, 1, 4, 17
    d, n_heads = 64, 4
    x = torch.rand(B * V * J, T * V, d)
    rays = torch.randn(B, V, J, 3)
    rays = rays / rays.norm(dim=-1, keepdim=True)
    layer = GeoBiasedAttention(d, n_heads, V)
    out = layer(x, rays)
    assert out.shape == x.shape
    print("geometry-aware cross-view attention bias prototype passed")
```

## 1. Technical report

The MotionFlow-MultiView fusion family already models aleatoric uncertainty, but it is not yet calibrated. The key existing pieces are:

- `motionflow_mv/fusion/ray_attention_temporal_uncertainty_model.py` replaces the sigmoid per-view weight with a Gaussian log-variance head and weights DLT as  
  \[
  w_{v,j}=c_{v,j}\,\exp(-\log\sigma^2_{v,j})
  \]
  It supervises uncertainty with a reprojection negative log-likelihood  
  \[
  \mathcal L_{\text{NLL}}=\frac12\Bigl(\frac{e_{v,j}^2}{\sigma^2_{v,j}}+\log\sigma^2_{v,j}\Bigr)
  \]
  where \(e^2_{v,j}\) is the per-view squared reprojection error.
- `motionflow_mv/fusion/ray_attention_temporal_residual_v3_model.py` predicts a weight/uncertainty pair but only uses it for residual feature pooling, with no explicit NLL supervision.
- `motionflow_mv/fusion/ray_attention_temporal_crossview_uncertainty_residual_learned_tri_v1_model.py` combines uncertainty-weighted DLT, a differentiable Gauss-Newton (GN) refinement, and a residual MLP; its training script is `experiments/train_ray_attention_temporal_crossview_uncertainty_residual_learned_tri_v1_mpiinf3dhp.py`.
- `motionflow_mv/losses/reprojection.py` and `motionflow_mv/eval/metrics.py` provide reprojection MSE and 3D pose metrics.

The gap is that predicted variance is not calibrated to actual error. A calibrated model should satisfy  
\[
\mathbb E[e^2_{v,j}] \approx \sigma^2_{v,j}.
\]
Right now the network may learn overly confident or overly conservative variances, because the NLL weight is fixed and there is no post-hoc calibration stage.

Design decisions for a calibration module:

1. **Keep the heteroscedastic log-variance head.** It already produces per-view, per-joint uncertainty and fits the existing architecture.
2. **Add temperature scaling on the validation set.** Treat the predicted variance as \(\sigma^2\) and learn a scalar temperature \(\tau>0\) such that the calibrated variance is  
   \[
   \tilde\sigma^2_{v,j}=\tau\,\sigma^2_{v,j}.
   \]
   The closed-form MLE under Gaussian NLL is  
   \[
   \tau = \frac{1}{N}\sum \frac{e^2_{v,j}}{\sigma^2_{v,j}}.
   \]
3. **Report Expected Calibration Error (ECE).** Bin predictions by \(\sigma^2\), compare mean predicted variance with mean observed squared error in each bin.
4. **Wire calibration into the model forward pass.** Add an optional `temperature` argument so inference can use the calibrated variance with `log_var_cal = log_var + log(tau)`.
5. **Do not change the training loop yet.** Post-hoc calibration is a minimal first step; only if it helps should we add a calibration-aware training term.

This approach is standard (Guo et al., “On Calibration of Modern Neural Networks”, 2017) and directly applicable because the existing models already output `log_var`.

## 3. Minimal calibration snippet

```python
# motionflow_mv/eval/calibration.py
import math
import torch

def gaussian_nll(errors_sq: torch.Tensor, log_var: torch.Tensor) -> torch.Tensor:
    """Gaussian NLL: 0.5 * (e^2 / sigma^2 + log sigma^2)."""
    return 0.5 * (errors_sq * torch.exp(-log_var) + log_var)

def fit_temperature_scale(errors_sq: torch.Tensor, log_var: torch.Tensor,
                          eps: float = 1e-6) -> torch.Tensor:
    """Closed-form MLE for tau under calibrated variance tau * sigma^2."""
    sigma2 = torch.exp(log_var)
    tau = (errors_sq / (sigma2 + eps)).mean()
    return tau.clamp(min=1e-3, max=1e3)

def expected_calibration_error(errors_sq: torch.Tensor, log_var: torch.Tensor,
                               n_bins: int = 10) -> float:
    sigma2 = torch.exp(log_var)
    quantiles = torch.quantile(sigma2, torch.linspace(0.0, 1.0, n_bins + 1))
    ece = 0.0
    total = sigma2.numel()
    for lo, hi in zip(quantiles[:-1], quantiles[1:]):
        mask = (sigma2 >= lo) & (sigma2 <= hi)
        if mask.sum() == 0:
            continue
        pred = sigma2[mask].mean()
        obs = errors_sq[mask].mean()
        ece += mask.sum().item() / total * abs(pred - obs)
    return ece
```

<subagent agent_id="agent-213" item="design_hierarchical_temporal_model" outcome="completed"># Hierarchical Temporal Model — Design Report

## 1. Technical summary

Current temporal models in `motionflow_mv/fusion/` apply a **single-scale** temporal transformer over all `(view, joint)` tokens (`ray_attention_temporal_model.py`) or use parallel dilated convolutions (`multiscale_temporal_conv_model.py`). Human motion, however, is naturally multi-scale: fast joint-level noise/oscillations, medium-range limb coordination, and slow action-level context. A hierarchical temporal model explicitly represents these scales and fuses them before predicting view weights.

### Proposed architecture: `RayAttentionFusionModelTemporalHierarchical`

Built on top of the existing per-frame ray-attention encoder (`_extract_frame_features`), it adds a **temporal feature pyramid** with three levels:

| Level | Operator | Captures |
|---|---|---|
| **Local** | Parallel 1-D temporal convolutions (`k=3,5,7`, dilations `1,2,4`) | High-frequency smoothing, per-joint noise filtering |
| **Mid** | Standard temporal self-attention (`n_temporal_layers=2`) | Medium-range occlusion reasoning, motion continuity |
| **Global** | Temporal average pooling + learned scale embedding | Long-range action phase and drift correction |

Given per-frame features \(F \in \mathbb{R}^{B \times T \times V \times J \times d}\):

\[
F_{\text{local}} = \text{TemporalConvBank}(F)
\]

\[
F_{\text{mid}} = \text{TransformerEncoder}(F)
\]

\[
F_{\text{global}} = \text{Broadcast}\left(\frac{1}{T}\sum_{t} F_t\right) + E_{\text{scale}}
\]

Fused features are concatenated and projected back to \(d\):

\[
F_{\text{fus}} = F + \text{LayerNorm}\left(W \cdot [F_{\text{local}}; F_{\text{mid}}; F_{\text{global}}]\right)
\]

Following `ray_attention_temporal_residual_model.py`, the fused per-view features are pooled per joint and used to predict a residual correction \(\Delta X\):

\[
\hat{X} = X_{\text{DLT}} + \text{MLP}\left([\text{Pool}(F_{\text{fus}}), X_{\text{DLT}}]\right)
\]

This combines geometric inductive bias (weighted DLT) with learned multi-scale temporal reasoning.

### Key design decisions
1. **Keep the per-frame encoder frozen** — reuse the validated v3 view/joint attention from existing temporal models.
2. **Additive fusion with residual connection** — avoids gradient instability when stacking multiple temporal branches.
3. **Modular scale branches** — each level can be ablated independently (`local_only`, `mid_only`, `global_only`).
4. **No new loss** — reuse 3D MSE + optional reprojection loss already used in `train_ray_attention_temporal_residual_mpiinf3dhp.py`.

### Risks
- Memory roughly doubles because of the parallel local and mid branches.
- The gain must be validated against the strong baseline in `docs/swarm_iter6/temporal_crossview_residual_report.md`.

"""Hierarchical temporal ray-aware attention fusion.

Three-scale temporal feature pyramid on top of the v3 per-frame encoder.
Levels: local 1-D convolutions, mid-range temporal self-attention, and
global temporal pooling.  Outputs are fused and fed to the residual
refinement head.
"""

from typing import List, Tuple

import torch
import torch.nn as nn

from .ray_attention_temporal_residual_model import RayAttentionFusionModelTemporalResidual
from .ray_attention_model import _triangulate_weighted_dlt


class _HierarchicalTemporalBlock(nn.Module):
    """Three-branch temporal block: local conv, mid attention, global pool.

    Input / output: ``(N, T, d)``.
    """

    def __init__(
        self,
        d: int,
        n_heads: int = 4,
        kernel_sizes: List[int] = None,
        dilations: List[int] = None,
    ):
        super().__init__()
        if kernel_sizes is None:
            kernel_sizes = [3, 5, 7]
            dilations = [1, 2, 4]

        # Local: parallel causal convolutions.
        self.local_branches = nn.ModuleList()
        for k, dil in zip(kernel_sizes, dilations):
            pad = (k - 1) * dil // 2
            self.local_branches.append(
                nn.Conv1d(d, d, kernel_size=k, dilation=dil, padding=pad, bias=False)
            )
        self.local_proj = nn.Linear(d * len(kernel_sizes), d)

        # Mid: single transformer layer over time.
        self.mid_layer = nn.TransformerEncoderLayer(
            d_model=d, nhead=n_heads, dim_feedforward=d * 2,
            batch_first=True, norm_first=True,
        )

        # Global: learnable scale embedding for the broadcast vector.
        self.global_scale = nn.Parameter(torch.randn(d) * 0.02)

        # Fusion.
        self.fusion = nn.Sequential(
            nn.Linear(d * 3, d),
            nn.ReLU(),
            nn.Linear(d, d),
        )
        self.norm = nn.LayerNorm(d)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        # x: (N, T, d)
        # Local branch.
        x_c = x.transpose(1, 2)  # (N, d, T)
        local_outs = [b(x_c) for b in self.local_branches]
        local = torch.cat(local_outs, dim=1).transpose(1, 2)  # (N, T, branches*d)
        local = self.local_proj(local)  # (N, T, d)

        # Mid branch.
        mid = self.mid_layer(x)  # (N, T, d)

        # Global branch.
        global_vec = x.mean(dim=1, keepdim=True)  # (N, 1, d)
        global_vec = global_vec + self.global_scale
        global_branch = global_vec.expand_as(x)  # (N, T, d)

        fused = torch.cat([local, mid, global_branch], dim=-1)  # (N, T, 3d)
        out = self.fusion(fused)  # (N, T, d)
        return self.norm(x + out)  # residual add + norm


class RayAttentionFusionModelTemporalHierarchical(RayAttentionFusionModelTemporalResidual):
    """Temporal ray-attention fusion with a hierarchical temporal pyramid."""

    def __init__(
        self,
        j: int = 17,
        d: int = 64,
        n_views: int = 4,
        n_heads: int = 4,
        n_joint_layers: int = 1,
        n_temporal_layers: int = 2,
        max_temporal_len: int = 256,
        residual_hidden: int = 128,
    ):
        super().__init__(
            j=j, d=d, n_views=n_views, n_heads=n_heads,
            n_joint_layers=n_joint_layers,
            n_temporal_layers=n_temporal_layers,
            max_temporal_len=max_temporal_len,
            residual_hidden=residual_hidden,
        )
        # Replace the single temporal transformer with hierarchical blocks.
        self.temporal_blocks = nn.ModuleList([
            _HierarchicalTemporalBlock(d, n_heads)
            for _ in range(n_temporal_layers)
        ])

    def forward(self, x, cameras=None, K=None, R=None, t=None):
        # Inherits everything from the residual model except temporal_blocks
        # is used in place of temporal_attn.
        return super().forward(x, cameras=cameras, K=K, R=R, t=t)
```

# Design Domain Adaptation for MotionFlow-MultiView

## 1. Motivation and Current State

The project already has two pieces of domain-adaptive machinery: a camera-domain MLP in `RayAttentionFusionModelTemporalDomain` (`motionflow_mv/fusion/ray_attention_temporal_model_domain.py`) and a residual refinement head in `RayAttentionFusionModelTemporalResidual` (`motionflow_mv/fusion/ray_attention_temporal_residual_model.py`).  
What is still missing is a unified *dataset-level* domain adaptation strategy that lets a single model trained on mixed sources (MPI-INF-3DHP, Human3.6M, 3DPW, synthetic SMPL) generalize across different camera rigs, skeleton scales, and motion distributions. This design combines geometry-normalized camera conditioning, adversarial domain-invariant training, and a bone-length regularizer on top of the latest temporal-residual/crossview architecture.

## 2. Key Design Decisions

1. **Geometry-normalized camera conditioning.**  
   Raw intrinsics `K` and extrinsics `t` are dataset-dependent. Normalize intrinsics by image resolution and extrinsics by scene scale:
   \[
   \tilde K = \operatorname{diag}(1/w, 1/h, 1)\,K, \qquad
   \tilde t_i = t_i / s,\; s = \frac{1}{V}\sum_i \|C_i\|_2
   \]
   The domain MLP receives `[flatten(\tilde K), flatten(R), flatten(\tilde t), \log s]` instead of the raw 21-D vector.

2. **Domain-agnostic feature injection.**  
   The camera-domain MLP from `ray_attention_temporal_model_domain.py` is reused, but its output is added to the per-view tokens *before* view/joint attention, so the whole encoder sees domain cues.

3. **Adversarial dataset-invariant training.**  
   A gradient-reversal domain head is attached to the pooled spatio-temporal feature. This minimizes pose loss while maximally confusing a dataset classifier, producing dataset-invariant representations.

4. **Bone-length consistency regularizer.**  
   A canonical bone-length prior is used to regularize the residual-corrected 3D pose, reducing scale drift across datasets.

5. **Optional synthetic-to-real warm-start.**  
   The synthetic generator (`experiments/generate_synthetic_multiview_dataset.py`) can pre-train the model before mixed-dataset fine-tuning.

## 3. Relevant Equations

Domain embedding and feature update:
\[
e_d = \operatorname{MLP}_d([\operatorname{flatten}(\tilde K), \operatorname{flatten}(R), \operatorname{flatten}(\tilde t), \log s])
\]
\[
\tilde f = f_{\text{base}} + e_d
\]

Adversarial training loss:
\[
\mathcal L = \mathcal L_{\text{pose}} + \lambda_{\text{rep}}\mathcal L_{\text{reproj}} + \lambda_u\mathcal L_{\text{uncertainty}} + \lambda_{\text{dom}}\mathcal L_{\text{domain-cls}}
\]
where the gradient reversal layer multiplies gradients by `-\alpha`.

Bone-length loss (canonical 17-joint skeleton):
\[
\mathcal L_{\text{bone}} = \frac{1}{J}\sum_j \bigl|\|X_j - X_{\text{parent}(j)}\|_2 - b_j^*\bigr|
\]

# motionflow_mv/fusion/ray_attention_temporal_domain_adaptive_model.py
import torch
import torch.nn as nn
from .ray_attention_temporal_residual_v3_model import RayAttentionFusionModelTemporalResidualUncertainty


class GradientReversalFn(torch.autograd.Function):
    @staticmethod
    def forward(ctx, x, alpha):
        ctx.alpha = alpha
        return x

    @staticmethod
    def backward(ctx, grad_output):
        return -ctx.alpha * grad_output, None


class DomainAdaptiveTemporalResidualModel(RayAttentionFusionModelTemporalResidualUncertainty):
    def __init__(self, n_domains=3, alpha=1.0, image_size=(1280, 720), **kwargs):
        super().__init__(**kwargs)
        self.n_domains = n_domains
        self.alpha = alpha
        self.image_size = image_size

        # Geometry-normalized camera domain MLP (22-D input: K(9)+R(9)+t(3)+log_scale)
        self.domain_camera_mlp = nn.Sequential(
            nn.Linear(9 + 9 + 3 + 1, self.d),
            nn.ReLU(),
            nn.Linear(self.d, self.d),
        )

        # Dataset classifier on pooled temporal features
        self.domain_head = nn.Sequential(
            nn.Linear(self.d, self.d // 2),
            nn.ReLU(),
            nn.Linear(self.d // 2, n_domains),
        )

    def _normalize_cameras(self, K, R, t):
        h, w = self.image_size
        K_norm = K.clone()
        K_norm[..., 0, :] /= w
        K_norm[..., 1, :] /= h
        cam_center = -torch.einsum("bvij,bvj->bvi", R.transpose(-2, -1), t)
        s = cam_center.norm(dim=-1, keepdim=True).mean(dim=1, keepdim=True)
        t_norm = t / (s[..., None] + 1e-6)
        return K_norm, R, t_norm, torch.log(s)

    def forward(self, x, domain_labels=None, K=None, R=None, t=None, **kwargs):
        # Normalize and inject camera-domain embedding
        K_n, R_n, t_n, log_s = self._normalize_cameras(K, R, t)
        cam_vec = torch.cat([
            K_n.reshape(K_n.size(0), K_n.size(1), -1),
            R_n.reshape(R_n.size(0), R_n.size(1), -1),
            t_n,
            log_s[:, :, None].expand(-1, K_n.size(1), -1),
        ], dim=-1)
        # feat_pooled would be exposed from the parent forward
        pred_3d, weights, extra = super().forward(x, K=K, R=R, t=t, **kwargs)

        # Domain prediction
        feat = self.feat_pooled  # (B*T, J, d) exposed from parent
        feat_flat = feat.mean(dim=1)  # (B*T, d)
        reversed_feat = GradientReversalFn.apply(feat_flat, self.alpha)
        domain_logits = self.domain_head(reversed_feat)

        return pred_3d, weights, domain_logits


# Minimal training-loop fragment
for xb, yb, K, R, t, domain_ids in mixed_loader:
    optimizer.zero_grad()
    pred, weights, domain_logits = model(xb, K=K, R=R, t=t, domain_labels=domain_ids)
    pose_loss = mse(pred, yb)
    domain_loss = ce(domain_logits, domain_ids)
    loss = pose_loss + lambda_domain * domain_loss
    loss.backward()
    optimizer.step()

## 1. Technical Report (≤500 words)

**Topic:** implement_robust_triangulation_baseline

**Goal.** Add a strong, non-learned robust triangulation baseline to the MotionFlow-MultiView fusion plugin family. It should handle sparse 2D outliers and missing views without training, and serve as a geometric reference for `ray_attention`, `robust_triangulation`, and other learned methods.

**Design decisions.**

1. **Iteratively reweighted least squares (IRLS) on reprojection residuals.** Start from the confidence-weighted DLT estimate, compute per-view reprojection residuals, and update view weights with a robust M-estimator. Iterate a fixed number of times. This is a standard calibrated multi-view geometry baseline.

2. **M-estimator: Huber or Charbonnier.** The Huber kernel bounds the influence of gross outliers while preserving inliers. Charbonnier provides a smooth alternative. Both are cheap, differentiable in `torch`, and require only a pixel threshold.

3. **Initialize from detector confidence.** The initial DLT uses `w_v = confidence_v`. The robust stage multiplies by the M-estimator weight, so bad views are down-weighted twice: once by the detector and once by geometry.

4. **Optional hard consistency guard.** After IRLS, zero views whose residual exceeds a pixel threshold and re-triangulate once. This closes the gap between soft weighting and hard outlier rejection.

**Equations.**

Weighted DLT at iteration `k`:

\[
X^k = \arg\min_X \| \sqrt{W^k} A(X) \|^2
\]

Per-view reprojection residual:

\[
r_v^k = \| \pi_v(X^k) - x_v \|_2
\]

Huber weight update with parameter `δ`:

\[
\psi(r) = \begin{cases} 1 & r \le \delta \\ \delta / r & r > \delta \end{cases}
\quad \Rightarrow \quad
w_v^{k+1} = \text{confidence}_v \cdot \psi(r_v^k)
\]

Charbonnier weight update with parameter `ε`:

\[
\psi(r) = \left(1 + \frac{r^2}{\varepsilon^2}\right)^{-1/2}
\]

Hard guard:

\[
w_v^{\text{final}} = 0 \quad \text{if} \quad r_v^K > \tau
\]

```python
"""Minimal prototype: IRLS robust triangulation vs plain DLT.

Run with:
    python docs/swarm_iter_next/implement_robust_triangulation_baseline/demo_robust_triangulation.py
"""

import numpy as np


def build_projection_matrix(K, R, t):
    Rt = np.hstack([R, t.reshape(3, 1)])
    return K @ Rt


def project(P, X):
    X = np.atleast_2d(X)
    Xh = np.concatenate([X, np.ones((X.shape[0], 1))], axis=-1)
    xh = (P @ Xh.T).T
    return xh[:, :2] / xh[:, 2:3]


def triangulate_dlt(points_2d, proj_matrices, weights=None):
    points_2d = np.asarray(points_2d, dtype=np.float64)
    proj_matrices = np.asarray(proj_matrices, dtype=np.float64)
    V = points_2d.shape[0]
    if weights is None:
        weights = np.ones(V, dtype=np.float64)
    else:
        weights = np.asarray(weights, dtype=np.float64).reshape(V)
        weights = np.sqrt(weights + 1e-6)

    A = []
    for (u, v), P, w in zip(points_2d, proj_matrices, weights):
        A.append(w * (u * P[2] - P[0]))
        A.append(w * (v * P[2] - P[1]))
    A = np.stack(A)
    _, _, vt = np.linalg.svd(A)
    X = vt[-1]
    return (X[:3] / X[3]).astype(np.float64)


def reprojection_residuals(X, points_2d, proj_matrices):
    residuals = []
    for v, P in enumerate(proj_matrices):
        Xh = np.append(X, 1.0)
        xh = P @ Xh
        x_proj = xh[:2] / xh[2]
        residuals.append(np.linalg.norm(x_proj - points_2d[v]))
    return np.asarray(residuals)


def triangulate_robust_irls(points_2d, proj_matrices, confidences,
                           kernel="huber", delta_px=5.0, n_iter=5,
                           hard_thresh_px=10.0):
    V = points_2d.shape[0]
    confidences = np.asarray(confidences, dtype=np.float64).reshape(V)
    weights = confidences.copy()

    X = triangulate_dlt(points_2d, proj_matrices, weights=weights)

    for _ in range(n_iter):
        residuals = reprojection_residuals(X, points_2d, proj_matrices)
        if kernel == "huber":
            psi = np.where(residuals <= delta_px, 1.0, delta_px / residuals)
        elif kernel == "charbonnier":
            psi = 1.0 / np.sqrt(1.0 + (residuals / delta_px) ** 2)
        else:
            raise ValueError(f"Unknown kernel: {kernel}")
        weights = confidences * psi
        X = triangulate_dlt(points_2d, proj_matrices, weights=weights)

    if hard_thresh_px is not None:
        residuals = reprojection_residuals(X, points_2d, proj_matrices)
        weights[residuals > hard_thresh_px] = 0.0
        if weights.sum() == 0:
            weights = np.ones(V, dtype=np.float64)
        X = triangulate_dlt(points_2d, proj_matrices, weights=weights)

    return X, weights


def make_cameras():
    intrinsics = [np.diag([1000.0, 1000.0, 1.0]) for _ in range(4)]
    for K in intrinsics:
        K[0, 2] = 320.0
        K[1, 2] = 240.0

    centers = [
        np.array([2.0, 0.0, 0.0]),
        np.array([-2.0, 0.0, 0.0]),
        np.array([0.0, 2.0, 0.0]),
        np.array([0.0, -2.0, 0.0]),
    ]
    Rs, ts = [], []
    for c in centers:
        z = -c / np.linalg.norm(c)
        up = np.array([0.0, 0.0, 1.0])
        x = np.cross(up, z)
        x /= np.linalg.norm(x)
        y = np.cross(z, x)
        R = np.stack([x, y, z], axis=0)
        Rs.append(R)
        ts.append(-R @ c)
    return intrinsics, np.stack(Rs), np.stack(ts)


def main():
    np.random.seed(42)
    Ks, Rs, ts = make_cameras()
    P = np.stack([build_projection_matrix(K, R, t) for K, R, t in zip(Ks, Rs, ts)])

    X_true = np.array([0.3, -0.1, 1.5])
    points_2d = project(P, X_true)
    noise = np.random.randn(*points_2d.shape) * 2.0
    points_2d_noisy = points_2d + noise
    points_2d_noisy[2] += np.array([80.0, 60.0])

    confidences = np.ones(4, dtype=np.float64)
    confidences[2] = 0.1

    X_dlt = triangulate_dlt(points_2d_noisy, P)
    X_conf = triangulate_dlt(points_2d_noisy, P, weights=confidences)
    X_rob, w_rob = triangulate_robust_irls(
        points_2d_noisy, P, confidences,
        kernel="huber", delta_px=5.0, n_iter=5, hard_thresh_px=10.0
    )

    print("True point  :", X_true)
    print("DLT         :", X_dlt, "  error =", np.linalg.norm(X_dlt - X_true))
    print("Conf-DLT    :", X_conf, "  error =", np.linalg.norm(X_conf - X_true))
    print("Robust IRLS :", X_rob, "  error =", np.linalg.norm(X_rob - X_true))
    print("Weights     :", w_rob.round(3))


if __name__ == "__main__":
    main()
```

# `docs/swarm_iter_next/design_occlusion_handling.md`

## 1. Problem & opportunity

The current best model, `RayAttentionFusionModelTemporalResidual` (`motionflow_mv/fusion/ray_attention_temporal_residual_model.py:38`), handles occlusion only *implicitly* via per-view weights and confidence dropout. It cannot tell “low-confidence detection” from “this joint is occluded in this view.” Failure analysis (`docs/swarm_iter5/failure_modes.md`) shows **26.3% of high-error frames** are occlusion cases, so an explicit occlusion branch is the next logical robustness gain.

## 2. Design: explicit visibility-gated fusion

Build a subclass that adds an `occlusion_head` to the temporal-residual model. The head predicts a per-view, per-joint soft visibility mask that gates the DLT weights. A lightweight auxiliary BCE loss supervises it from the random dropout augmentation already used in training.

Key design decisions:

1. **Head placement.** After the temporal transformer, pool the per-view features per joint and pass them through `nn.Linear(d, 1)` to yield occlusion logits `o_{t,v,j}`.
2. **Soft visibility.**  
   \[
   v_{t,v,j}=1-\sigma(o_{t,v,j})=\sigma(-o_{t,v,j})
   \]
   where `σ` is the sigmoid. High `v` means visible; low means occluded.
3. **Gated DLT weights.** The existing weight head produces logits `z`; the final DLT weight becomes  
   \[
   \tilde w_{t,v,j}=c_{t,v,j}\,\sigma(z_{t,v,j})\,v_{t,v,j}
   \]
   where `c` is the detector confidence.
4. **Auxiliary occlusion loss.** The random-joint dropout in `experiments/train_ray_attention_temporal_residual_mpiinf3dhp.py:118` already zeroes out observations. Treat those zeroed observations as ground-truth occlusions and add  
   \[
   \mathcal L_{\text{occ}}=\text{BCE}(v,\,o_{\text{gt}})
   \]
   with a small weight, e.g. `λ_occ = 0.1`.
5. **Minimum-view fallback.** If the soft visible count for a joint is below 2, the DLT system is ill-conditioned. Use a differentiable fallback: when `∑_v v < 2`, replace `v` with `1` (all views) and rely on the residual head to clean up. Alternatively, fall back to the previous temporal frame’s 3D estimate; this is left as a future extension.
6. **Keep the residual head.** The same `residual_mlp` is retained and receives the raw DLT output, so the model can compensate when the visibility gate is imperfect.

# Design: Synthetic Data Augmentation for MotionFlow-MultiView

**Topic:** `design_synthetic_augmentation` — upgrading the synthetic pipeline and on-the-fly augmentation for the ICRA/CVPR 2027 submission.  
**Target model:** `RayAttentionFusionModelTemporalCrossviewUncertaintyResidualLearnedTriV1` (`motionflow_mv/fusion/ray_attention_temporal_crossview_uncertainty_residual_learned_tri_v1_model.py`).  
**Key existing files:** `experiments/generate_synthetic_multiview_dataset.py`, `experiments/train_ray_attention_temporal_crossview_uncertainty_residual_learned_tri_v1_mpiinf3dhp.py`, `motionflow_mv/data/webbridge_loader.py`, `motionflow_mv/data/synthetic_3d_dataset.py`.

## 1. Current state and gap

The existing synthetic generator (`experiments/generate_synthetic_multiview_dataset.py`) produces single-frame SMPL poses with Brownian-motion latent angles, projects them through H36M-matched cameras, and adds Gaussian pixel noise, per-joint occlusion, and 2D outliers. It already supports two camera modes (`h36m` and `legacy`) and a configurable world scale. However, it does **not** produce temporal clips, uses unrealistic Brownian motion rather than mocap, and is only wired to the older non-temporal `RayAttentionFusionModel` trainer (`experiments/train_ray_attention_synthetic.py`).

Current on-the-fly augmentation (`augment_clip` in `experiments/train_ray_attention_temporal_crossview_uncertainty_residual_learned_tri_v1_mpiinf3dhp.py:113`) is lightweight but primitive: uniform `0.5 px` noise, 10% random confidence dropout, and 2% uniform outliers. It ignores per-joint detector statistics, structured occlusion, camera failure, and temporal deformations.

## 2. Proposed design decisions

1. **AMASS-driven motion.** Replace Brownian latent angles with real AMASS pose sequences so synthetic clips contain plausible human dynamics. This directly feeds the temporal transformer with motion that matches the target distribution.

2. **Domain-randomized camera rigs.** Sample camera count `V ∈ {3,4,6,8}`, focal length, principal point, baseline, and height from wide ranges during synthetic generation, then optionally re-normalize to a canonical rig during training. This improves cross-dataset generalization.

3. **Calibrated, per-joint noise model.** Collect 2D reprojection residuals from the training set, estimate a per-joint `2 × 2` covariance `Σ_j`, and draw `ε ~ N(0, Σ_j)` during augmentation. Limb joints (wrist/ankle) receive larger perturbations than torso joints.

4. **Structured occlusion / view dropout.**
   - *View failure:* zero an entire camera for a whole clip with probability `p_view`.
   - *Joint-block occlusion:* zero a contiguous set of joints for a temporal window.
   - *Stripe dropout:* zero a vertical image strip for a contiguous window.

5. **Temporal augmentation.** Apply clip-level speed perturbation (`stride ∈ {1,2,3}`), time reversal, window jitter (`clip_len ∈ [9,17]`), and frame dropout (blank 1–2 frames).

6. **Pre-train → fine-tune workflow.** Generate a large domain-randomized synthetic set, pre-train the full temporal model on synthetic clips, then fine-tune on real MPI-INF-3DHP / H36M with a reduced learning rate.

## 3. Key equations

- Calibrated 2D noise:
  ```
  x'_{t,v,j} = x_{t,v,j} + ε_{t,v,j},  ε ~ N(0, Σ_j)
  Σ_j = diag(σ_x,j², σ_y,j²)            (learned from detector residuals)
  ```

- Structured occlusion mask applied to confidence channel:
  ```
  c'_{t,v,j} = m_{t,v,j} · c_{t,v,j},  m_{t,v,j} ∈ {0,1}
  ```

- Temporal stride / reversal:
  ```
  x' = x[:, ::s, ...]                  (speed perturbation, s ∈ {1,2,3})
  x' = flip(x, dim=1)                  (time reversal with probability 0.5)
  ```

- Training loss remains the existing composite:
  ```
  L = MSE(X_pred, X_gt) + λ_r L_reproj + λ_u L_uncertainty_NLL
  ```

## 4. Expected impact and validation

- Lower synthetic-to-real transfer gap for MPI-INF-3DHP, where real training data is scarce.
- Better robustness to view dropout and occlusion because the model sees structured failures during pre-training.
- More stable uncertainty and residual heads because noise is calibrated to detector statistics rather than a single global `σ`.
- Smoke validation: pre-trained model should reach `< 5 mm` MPJPE on synthetic validation and a lower initial real-data validation error than a randomly initialized model.

    """Enhanced per-clip augmentation for (B, T, V, J, 3) tensors."""
    B, T, V, J, _ = x.shape

    # Temporal reversal and subsampling (whole-clip operations).
    if reverse_prob > 0 and torch.rand(1).item() < reverse_prob:
        x = torch.flip(x, dims=[1])
    if temporal_stride > 1:
        x = x[:, ::temporal_stride]

    # Per-joint std: torso/head < elbows/knees < wrist/ankle.
    per_joint_std = torch.full((J,), noise_std, device=x.device, dtype=x.dtype)
    limb = [4, 5, 6, 7, 10, 11, 12, 13]
    wrist_ankle = [8, 9, 14, 15, 16]
    per_joint_std[limb] *= joint_noise_scale
    per_joint_std[wrist_ankle] *= joint_noise_scale * 1.5
    noise = torch.randn_like(x[..., :2]) * per_joint_std.view(1, 1, 1, J, 1)
    x[..., :2] = x[..., :2] + noise

    # Structured occlusion: zero a contiguous joint block per (B, T, V).
    if occlusion_rate > 0:
        occ = torch.rand(B, T, V, 1, device=x.device) < occlusion_rate
        x[..., 2] = x[..., 2] * (~occ).float()

    # Random view dropout (entire camera missing for the clip).
    if view_dropout_rate > 0:
        view_mask = torch.rand(B, 1, V, 1, device=x.device) > view_dropout_rate
        x[..., 2] = x[..., 2] * view_mask.float()

    # Confidence dropout.
    if dropout_rate > 0:
        mask = torch.rand(B, T, V, J, device=x.device) > dropout_rate
        x[..., 2] = x[..., 2] * mask.float()

    # 2D outliers.
    if outlier_rate > 0:
        outlier_mask = torch.rand(B, T, V, J, device=x.device) < outlier_rate
        outlier = (torch.rand(B, T, V, J, 2, device=x.device) - 0.5) * 2 * outlier_scale
        x[..., :2] = torch.where(outlier_mask[..., None], outlier, x[..., :2])
        x[..., 2] = x[..., 2] * (~outlier_mask).float()

    return x


class SyntheticTemporalClipDataset(torch.utils.data.Dataset):
    """Yield clips from a synthetic .npz without crossing sequence boundaries."""

    def __init__(
        self,
        npz_path: str,
        clip_len: int = 13,
        frames_per_seq: int = 30,
        gt_scale: float = 1.0,
    ):
        data = np.load(npz_path)
        self.points_2d = torch.from_numpy(data["points_2d"]).float()
        self.confidences = torch.from_numpy(data["confidences"]).float()
        self.joints_3d = torch.from_numpy(data["joints_3d"]).float() * gt_scale
        self.K = torch.from_numpy(data["camera_K"]).float()
        self.R = torch.from_numpy(data["camera_R"]).float()
        self.t = torch.from_numpy(data["camera_t"]).float() * gt_scale

        self.clip_len = clip_len
        self.frames_per_seq = frames_per_seq
        self.num_seqs = self.points_2d.shape[0] // frames_per_seq

    def __len__(self):
        return self.num_seqs * (self.frames_per_seq - self.clip_len + 1)

    def __getitem__(self, idx):
        seq_idx = idx // (self.frames_per_seq - self.clip_len + 1)
        frame_offset = idx % (self.frames_per_seq - self.clip_len + 1)
        start = seq_idx * self.frames_per_seq + frame_offset
        end = start + self.clip_len
        x = torch.cat(
            [
                self.points_2d[start:end],
                self.confidences[start:end].unsqueeze(-1),
            ],
            dim=-1,
        )
        return x, self.joints_3d[start:end], self.K[start], self.R[start], self.t[start]


def collate_fn(batch):
    x = torch.stack([b[0] for b in batch], dim=0)
    y = torch.stack([b[1] for b in batch], dim=0)
    K = torch.stack([b[2] for b in batch], dim=0)
    R = torch.stack([b[3] for b in batch], dim=0)
    t = torch.stack([b[4] for b in batch], dim=0)
    return x, y, K, R, t

# Design Evaluation Protocol

**Topic:** `design_evaluation_protocol` — a reproducible, cross-dataset evaluation framework for the MotionFlow-MultiView ICRA/CVPR 2027 submission.

## 1. Technical Report

### Motivation
Current evaluation is fragmented: `experiments/eval_ray_attention_temporal_residual_v3.py` reports MPI-INF-3DHP numbers, `experiments/eval_ray_attention_v1_h36m.py` handles Human3.6M, and robustness tests are ad-hoc. For a publication-quality submission we need **one protocol** that defines canonical splits, metrics, corruptions, and reporting, while re-using the existing `motionflow_mv/eval/metrics.py` implementation.

### Key design decisions
1. **Canonical dataset splits**
   - **Human3.6M**: train on all actions of subjects S1, S5, S6, S7, S8; test on all actions of S9 and S11.
   - **MPI-INF-3DHP**: train on subjects S1–S5; test on subjects S6–S8 (all sequences).
   - Rationale: matches the most common literature baseline and removes ambiguity from the current smoke splits.

2. **Metrics**
   All metrics are computed by `motionflow_mv/eval/metrics.py`:
   - MPJPE: $\frac{1}{BJ}\sum_{b,j}\|\hat{X}_{bj}-X_{bj}\|_2$ (mm).
   - PA-MPJPE: same after rigid Procrustes alignment of each pose to GT.
   - PCK@$\tau$ mm: $\frac{1}{BJ}\sum_{b,j}\mathbb{1}[\|\hat{X}_{bj}-X_{bj}\|_2<\tau]$.
   - AUC: trapezoidal integral of PCK over thresholds $0$–$150$ mm, normalized by range.
   - Per-joint and per-sequence breakdowns for diagnostic tables.

3. **Robustness protocol**
   Standard corruption levels applied to the input 2D keypoints at test time only:
   - Gaussian noise: $\sigma \in \{0, 2, 5, 10\}$ px.
   - Joint dropout: randomly set confidence to zero for $p \in \{0, 0.25, 0.50\}$ of joints per view.
   - Outliers: replace a fraction $p \in \{0, 0.1, 0.2, 0.3\}$ of detections with a uniform outlier.
   - Occluded cameras: drop one or two entire views.

4. **Reproducibility**
   - Config-driven via YAML (`configs/eval_protocol.yaml`), extending `configs/train_ray_attention_reproducible.yaml`.
   - Deterministic seeding: `set_seed()` from `experiments/train_ray_attention_reproducible.py`.
   - Fixed checkpoint naming: `{model}_{dataset}_{seed}.pth`.
   - JSON outputs with full metadata.

5. **Cross-dataset generalization**
   Train on Human3.6M, evaluate on MPI-INF-3DHP and vice versa, after canonical skeleton mapping (17 joints).

- `motionflow_mv/eval/metrics.py` — `compute_all_metrics`, `pa_mpjpe`, `pck_auc`.

## (1) Concise technical report

### Design Visualization Paper Figures — Technical Report

**Goal.** Produce camera-ready figures for the ICRA/CVPR 2027 submission that explain *why* the advanced multi-view pose model works: a spatio-temporal ray-attention fusion network with uncertainty-weighted DLT, differentiable Gauss-Newton (GN) triangulation, and a residual refinement head.

**Key design decisions.**

1. **Expose intermediate pipeline stages.** The current `RayAttentionFusionModelTemporalCrossviewUncertaintyResidualLearnedTriV1` (`motionflow_mv/fusion/ray_attention_temporal_crossview_uncertainty_residual_learned_tri_v1_model.py`) returns only the final prediction. For paper figures we need three stages: raw weighted DLT (`X_dlt`), GN-refined (`X_gn`), and residual-corrected (`X_res`). A non-breaking `return_intermediates=True` flag returns `(pred_3d, weights, log_var, nll_loss, pred_3d_raw, pred_3d_gn, delta)`.

2. **Visualize uncertainty as a heatmap.** The uncertainty head predicts `log_var` per (view, joint). We render it as a per-view per-joint heatmap overlaid with DLT weights `w ∝ exp(-log_var) · confidence`. This validates that the model down-weights noisy or occluded views.

3. **Stage comparison figure.** One row per stage—DLT → GN → Residual—each beside ground truth. This supports the claim that triangulation supplies geometric consistency while the learned modules correct only structured residual error.

4. **Diagnostic bar charts and curves.** Add per-joint MPJPE, PCK-vs-threshold curves, and robustness grids. These reuse the orchestrator `experiments/generate_paper_figures_and_tables.py` and helpers in `experiments/lib/paper_figures.py`.

5. **Publication format.** Generate high-resolution PNG and vector PDFs using the matplotlib `Agg` backend for headless rendering on the A800/RTX 4090 workstations.

**Relevant equations.**

Weighted DLT triangulation:

\[
X_{\text{dlt}} = \text{weighted\_dlt}(p_{2d}, w, P), \quad w = e^{-\log\sigma^2} \cdot c
\]

Gauss-Newton refinement:

\[
(J^\top W J + \lambda I)\,\delta X = J^\top W r,\quad X_{\text{gn}} = X_{\text{dlt}} + \delta X
\]

Residual correction:

\[
\Delta X = \text{MLP}([f, X_{\text{gn}}]),\quad X = X_{\text{gn}} + \Delta X
\]

## 1. Concise technical report

### What the repo does
The MotionFlow-MultiView extension turns calibrated multi-view 2D keypoints into metric 3D human pose through a **temporal ray-attention fusion** head followed by a **lightweight residual refinement** head.

### Key design decisions (with file references)

1. **Geometry-first fusion.** The core inductive bias is a differentiable weighted DLT layer in `motionflow_mv/fusion/ray_attention_model.py` and `motionflow_mv/fusion/triangulation.py`. Instead of regressing 3D coordinates, the network predicts per-view, per-joint weights and feeds them to triangulation.

2. **Ray embeddings.** In `ray_attention_model.py`, each 2D point is lifted to a camera ray:
   ```text
   d_world = R^T K^{-1} [x, y, 1]^T
   ```
   The token is the concatenation of `(x, y, confidence)` and `(camera_center, ray_dir)`.

3. **Temporal + view + joint attention.** `ray_attention_temporal_model.py` adds a temporal transformer over `(view, joint)` tokens, then predicts weights and calls the DLT layer.

4. **Residual refinement.** `ray_attention_temporal_residual_model.py` triangulates a raw 3D pose `X_raw` and then adds a learned residual:
   ```text
   ΔX = MLP([f, X_raw])
   X = X_raw + ΔX
   ```
   This keeps the geometric consistency of DLT while correcting structured residual error.

5. **Plugin / IR integration.** The pipeline exposes a `MultiViewFusionPlugin` and outputs a `HumanMotionIR` (see `motionflow_mv/pipeline.py` and `motionflow_mv/ir/human_motion_ir.py`), decoupling pose fusion from downstream robot retargeting.

### Relevant equations

Weighted DLT for a single joint:
```text
A = [ w_v * (x_v P_v^{3} - P_v^{1});
      w_v * (y_v P_v^{3} - P_v^{2}) ]_v
X = argmin  ||A X||^2
```

Residual head:
```text
ΔX = MLP([f, X_raw])
X  = X_raw + ΔX
```

Training loss:
```text
L = ||X - X_gt||_2^2 + λ_reproj Σ_v ||π_v(X) - x_v||_2^2

## 2. Related Work

**Classical multi-view triangulation.** Calibrated triangulation recovers 3D points from matched 2D observations. The Direct Linear Transform (DLT) builds a linear system from projection matrices and solves for the point that best satisfies all rays in a least-squares sense [Hartley-Zisserman 2004]. Confidence-weighted variants down-weight noisy views but remain deterministic and brittle to occlusion and detector bias.

**Learned multi-view fusion.** Iskakov et al. introduced learnable triangulation, predicting per-view weights before triangulating [ICCV 2019]. Recent work continues the shift from direct 3D regression to geometry-aware learned fusion: ray-based transformers [RUMPL 2025], state-space view fusion [MV-SSM, CVPR 2025], hypergraph cover optimization [COMPOSE 2026], and dense spatio-temporal warping [DenseWarper 2026] all fuse multi-view evidence before lifting to 3D. These methods improve robustness but usually output the fused triangulation directly.

**Temporal pose models and residual refinement.** Temporal transformers and 1-D convolutions enforce smoothness across frames [MotionBERT, SmoothNet]. Residual learning is common in 2D pose networks; applying it after explicit triangulation is less explored. Our approach adds a small MLP residual head on top of a differentiable triangulation layer, so the network only has to learn the structured leftover error while preserving metric scale.

**Robotics-oriented pose pipelines.** Systems such as MotionFlow, EasyMocap, and ScoreHMR produce per-view pose estimates, but few expose a lightweight, interchangeable fusion plugin that feeds a robot-facing intermediate representation. Our `MultiViewFusionPlugin` consumes per-view 2D keypoints and calibrated cameras and emits a `HumanMotionIR` with 3D pose, per-joint confidence, and view-support metadata, enabling downstream retargeting and policy training.

**Positioning.** Unlike prior work that regresses 3D coordinates or stops at weighted triangulation, we decompose the problem as *temporal ray-attention fusion + differentiable weighted DLT + post-triangulation residual refinement*. This preserves the geometric correctness of triangulation, adds learned robustness to occlusion/outliers, and exports an uncertainty-aware `HumanMotionIR` for robotics applications.
```

## 1. Technical Report

The current best model stack is `RayAttentionFusionModelTemporalCrossviewUncertaintyResidualLearnedTriV1` (`motionflow_mv/fusion/ray_attention_temporal_crossview_uncertainty_residual_learned_tri_v1_model.py`). ### Key design decisions

1. **Geometric triangulation + learned residual correction.** The network predicts per-view weights and triangulates a raw 3D pose `X_raw`; a small MLP then predicts a per-joint residual `ΔX`. This keeps metric scale while correcting systematic leftover error.
2. **Uncertainty weighting.** The uncertainty head predicts `log_var`, and weights become:
   ```
   w = exp(-log_var) * confidence
   ```
3. **Differentiable Gauss-Newton refinement.** After weighted DLT, a Gauss-Newton step minimizes the weighted reprojection residual:
   ```
   X_{k+1} = X_k + (J^T W J + λI)^{-1} J^T W r

<subagent agent_id="agent-227" item="design_a800_benchmark_script" outcome="completed"># Design: A800 Benchmark Script for MotionFlow-MultiView

## 1. Technical Report

Existing benchmarks in the repo target a local RTX 4090 and are inference-only (`experiments/benchmark_residual_temporal.py`, `experiments/benchmark_inference_v3.py`). The A800 node (`a800-D`) is the intended production/training host, yet there is no standardized script that reports training throughput, inference latency, and GPU memory headroom on that hardware. This design proposes a reproducible, data-agnostic benchmark that can be run before every paper iteration to detect regressions and justify scaling decisions.

**Key design decisions:**

1. **Synthetic fixed rig, no dataset dependency.** Reuses the pure-torch `_FixedRig` pattern from `experiments/benchmark_residual_temporal.py`, so the script runs on any CUDA host without WebBridge/MPI data.
2. **Measure both inference and training.** The RTX 4090 script only times `torch.no_grad()` forward passes. This A800 script also runs a forward+backward loop with MSE loss to report clips/sec and peak training memory.
3. **Expose `torch.compile` and multi-GPU toggles.** A800 has large memory and often runs with DDP; the script supports `--compile` and `--device` to compare eager vs. compiled, and single vs. multi-GPU throughput.
4. **Standardized JSON + Markdown outputs.** Results mirror the existing `outputs/benchmark_residual_temporal_4090.json` format and are written to `outputs/benchmark_a800_<timestamp>.json`.

**Metrics & equations:**

- Inference latency per clip:
  \[
  L_{\text{ms}} = \frac{t_{\text{end}} - t_{\text{start}}}{N_{\text{iters}}} \times 1000
  \]
- Throughput:
  \[
  R = \frac{B \cdot N_{\text{iters}}}{t_{\text{end}} - t_{\text{start}}} \quad \text{clips/s}
  \]
- Peak GPU memory:
  \[
  M_{\max} = \frac{\max_i \text{torch.cuda.max_memory_allocated}(i)}{1024^3} \quad \text{GB}
  \]

**References to existing files:**
- `motionflow_mv/fusion/ray_attention_temporal_residual_model.py` – target model.
- `experiments/benchmark_residual_temporal.py` – inference-only RTX 4090 benchmark.
- `experiments/train_ray_attention_temporal_residual_mpiinf3dhp.py` – training loop helpers.
- `scripts/audit_a800_readonly_v5.py` – A800 host inventory.

## 3. Prototype Script

```python
"""A800 benchmark prototype for RayAttentionFusionModelTemporalResidual.

Measures inference latency, inference throughput, and training throughput
on CUDA. Uses a synthetic fixed rig so no dataset is required.

Usage (from repo root):
    python docs/swarm_iter_next/design_a800_benchmark_script/benchmark_a800_prototype.py \
        --mode both --batch_sizes 1 4 8 16 --iters 100

Outputs:
    outputs/benchmark_a800_<timestamp>.json
    outputs/benchmark_a800_<timestamp>.md
"""

import argparse
import json
import math
import sys
import time
from datetime import datetime, timezone
from pathlib import Path

import torch
import torch.nn as nn

sys.path.insert(0, str(Path(__file__).resolve().parents[3]))

from motionflow_mv.fusion.ray_attention_temporal_residual_model import (
    RayAttentionFusionModelTemporalResidual,
)


class _FixedRig:
    """Single fixed camera rig, built with pure torch/math."""

    def __init__(self, V: int, device: torch.device):
        self.V = V
        self.K, self.R, self.t = self._build_rig(device)

    @staticmethod
    def _rotation_y(angle: float) -> torch.Tensor:
        c = math.cos(angle)
        s = math.sin(angle)
        return torch.tensor(
            [[c, 0.0, s], [0.0, 1.0, 0.0], [-s, 0.0, c]], dtype=torch.float32
        )

    def _build_rig(self, device: torch.device):
        V = self.V
        Ks, Rs, ts = [], [], []
        radius = 5.0
        for i in range(V):
            fx = fy = 1000.0 + (i % 3) * 50.0
            cx, cy = 640.0, 360.0
            K = torch.tensor(
                [[fx, 0.0, cx], [0.0, fy, cy], [0.0, 0.0, 1.0]], dtype=torch.float32
            )
            Ks.append(K)
            angle = 2.0 * math.pi * i / V
            Rs.append(self._rotation_y(angle))
            t_vec = torch.tensor(
                [math.cos(angle) * radius, 0.0, math.sin(angle) * radius],
                dtype=torch.float32,
            )
            t_vec = t_vec / (t_vec.norm() + 1e-8) * radius
            ts.append(t_vec)
        return (
            torch.stack(Ks).to(device),
            torch.stack(Rs).to(device),
            torch.stack(ts).to(device),
        )

    def to(self, device: torch.device):
        return self.K.to(device), self.R.to(device), self.t.to(device)


def _dummy_batch(batch_size: int, T: int, V: int, J: int, device: torch.device):
    x = torch.randn(batch_size, T, V, J, 3, device=device)
    x[..., 2] = torch.sigmoid(x[..., 2])
    return x


def _run_inference(model, x, K, R, t):
    with torch.no_grad():
        _ = model(x, K=K, R=R, t=t)


def _run_training(model, x, K, R, t, optimizer, criterion):
    pred, _ = model(x, K=K, R=R, t=t)
    target = torch.zeros_like(pred)
    loss = criterion(pred, target)
    optimizer.zero_grad(set_to_none=True)
    loss.backward()
    optimizer.step()
    return loss.item()


def benchmark_inference(model, device, batch_size, T, V, J, warmup, iters, rig):
    model = model.to(device).eval()
    K, R, t = rig.to(device)
    x = _dummy_batch(batch_size, T, V, J, device)

    with torch.no_grad():
        for _ in range(warmup):
            _run_inference(model, x, K, R, t)
    torch.cuda.synchronize(device)

    start = time.perf_counter()
    with torch.no_grad():
        for _ in range(iters):
            _run_inference(model, x, K, R, t)
    torch.cuda.synchronize(device)
    elapsed = time.perf_counter() - start

    return {
        "batch_size": batch_size,
        "latency_ms": elapsed / iters * 1000.0,
        "throughput_clips_s": batch_size * iters / elapsed,
        "peak_memory_gb": torch.cuda.max_memory_allocated(device) / (1024**3),
    }


def benchmark_training(model, device, batch_size, T, V, J, warmup, iters, rig):
    model = model.to(device).train()
    K, R, t = rig.to(device)
    x = _dummy_batch(batch_size, T, V, J, device)
    optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)
    criterion = nn.MSELoss()

    for _ in range(warmup):
        _run_training(model, x, K, R, t, optimizer, criterion)
    torch.cuda.reset_peak_memory_stats(device)
    torch.cuda.synchronize(device)

    start = time.perf_counter()
    for _ in range(iters):
        _run_training(model, x, K, R, t, optimizer, criterion)
    torch.cuda.synchronize(device)
    elapsed = time.perf_counter() - start

    return {
        "batch_size": batch_size,
        "latency_ms": elapsed / iters * 1000.0,
        "throughput_clips_s": batch_size * iters / elapsed,
        "peak_memory_gb": torch.cuda.max_memory_allocated(device) / (1024**3),
    }


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--mode", type=str, default="both", choices=["inference", "training", "both"])
    parser.add_argument("--batch_sizes", type=int, nargs="+", default=[1, 4, 8, 16])
    parser.add_argument("--n_views", type=int, default=14)
    parser.add_argument("--j", type=int, default=28)
    parser.add_argument("--clip_len", type=int, default=13)
    parser.add_argument("--d", type=int, default=64)
    parser.add_argument("--residual_hidden", type=int, default=128)
    parser.add_argument("--warmup", type=int, default=20)
    parser.add_argument("--iters", type=int, default=100)
    parser.add_argument("--compile", action="store_true")
    parser.add_argument("--device", type=str, default="cuda:0")
    parser.add_argument("--out_dir", type=str, default="outputs")
    parser.add_argument("--smoke", action="store_true")
    args = parser.parse_args()

    if args.smoke:
        args.batch_sizes = [1, 4]
        args.warmup = 2
        args.iters = 5

    device = torch.device(args.device if torch.cuda.is_available() else "cpu")
    V, J, T = args.n_views, args.j, args.clip_len
    rig = _FixedRig(V, device)

    model = RayAttentionFusionModelTemporalResidual(
        j=J,
        d=args.d,
        n_views=V,
        n_heads=4,
        n_joint_layers=1,
        n_temporal_layers=2,
        max_temporal_len=256,
        residual_hidden=args.residual_hidden,
    )
    if args.compile and torch.cuda.is_available():
        model = torch.compile(model)

    param_count = sum(p.numel() for p in model.parameters())
    timestamp = datetime.now(timezone.utc).strftime("%Y%m%d_%H%M%S")
    out_dir = Path(args.out_dir)
    out_dir.mkdir(exist_ok=True)

    results = {
        "model": "RayAttentionFusionModelTemporalResidual",
        "params": param_count,
        "d": args.d,
        "residual_hidden": args.residual_hidden,
        "views": V,
        "joints": J,
        "clip_len": T,
        "device": str(device),
        "compiled": args.compile,
        "timestamp": timestamp,
        "modes": {},
    }

    if args.mode in ("inference", "both"):
        results["modes"]["inference"] = [
            benchmark_inference(model, device, B, T, V, J, args.warmup, args.iters, rig)
            for B in args.batch_sizes
        ]

    if args.mode in ("training", "both"):
        results["modes"]["training"] = [
            benchmark_training(model, device, B, T, V, J, args.warmup, args.iters, rig)
            for B in args.batch_sizes
        ]

    json_path = out_dir / f"benchmark_a800_{timestamp}.json"
    json_path.write_text(json.dumps(results, indent=2))

    md_lines = [
        f"# A800 Benchmark – {timestamp}",
        "",
        f"- Model: `{results['model']}`",
        f"- Parameters: {param_count:,}",
        f"- d={args.d}, residual_hidden={args.residual_hidden}",
        f"- Views={V}, Joints={J}, Clip length={T}",
        f"- Device: `{device}` (compiled={args.compile})",
        "",
    ]
    for mode_name, mode_results in results["modes"].items():
        md_lines.extend([f"## {mode_name.capitalize()}", ""])
        md_lines.append("| Batch | Latency (ms) | Throughput (clips/s) | Peak mem (GB) |")
        md_lines.append("|------:|-------------:|---------------------:|--------------:|\")
        for r in mode_results:
            md_lines.append(
                f\"| {r['batch_size']:>5} | {r['latency_ms']:>12.2f} | "
                f\"{r['throughput_clips_s']:>20.2f} | {r['peak_memory_gb']:>13.2f} |"
            )
        md_lines.append("")

    md_path = out_dir / f"benchmark_a800_{timestamp}.md"
    md_path.write_text("\n".join(md_lines))

    print(f"Saved JSON: {json_path}")
    print(f"Saved MD:   {md_path}")
    print(json.dumps(results, indent=2))


if __name__ == "__main__":
    main()
